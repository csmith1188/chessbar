# ChessBar
## Setting up your own instance of Chessbar
1. In the command prompt, run `init.bat`.
2. In the `.env` file, fill out the correct information.

### If you want to reset the database without resetting `.env`, run `reset-db.bat`

## Touch Controls (Mobile)
- **Tap and drag** a piece to move it
- **Long press** (hold for 0.5s) on a square to highlight it or draw arrows
- **Tap anywhere** to clear arrows and highlights
